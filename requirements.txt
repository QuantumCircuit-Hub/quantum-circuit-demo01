# Runtime dependencies for the DEPLOYED Streamlit app (app.py) only.
#
# The app reads pre-generated JSON files under data/ and never calls
# qiskit or mqt-bench at runtime -- it only needs streamlit (the UI) and
# networkx (to model the evolution graph, e.g. topological sort and
# generation layout). Kept intentionally minimal, with transitive
# dependencies left unpinned so pip can resolve them fresh for whatever
# platform is deploying (e.g. Streamlit Community Cloud's Linux
# environment) -- a large list of exact pins for a different platform
# was causing dependency resolution to hang during deployment.
#
# For the full local development environment (needed to run the
# scripts/ that (re)generate circuit data: qiskit, mqt-bench, pytest,
# etc.), see requirements-dev.txt instead.
streamlit==1.63.0
networkx==3.6.1
